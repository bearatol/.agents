# CRO Audit

Define the page goal, traffic mix, user intent, funnel context, device split,
baseline data, and known research. Review relevance, clarity, motivation, proof,
friction, anxiety, accessibility, performance, and measurement. Separate
observations from hypotheses. Return prioritized findings with evidence,
expected mechanism, effort, risk, and a test or validation method. Never promise
uplift without an experiment.
