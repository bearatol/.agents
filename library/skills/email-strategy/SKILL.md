# Email Strategy

Map subscriber sources, consent, lifecycle stages, desired behaviors, value
exchange, frequency, segmentation, deliverability constraints, and measurement.
Define which messages belong in automation and which require editorial choice.
Return a lifecycle map, sequence inventory, content themes, trigger rules,
suppression rules, and metrics. Respect unsubscribe, privacy, and regional
requirements.
