# Nurture Sequence

Identify the audience's current belief, desired belief, recurring problems,
proof needs, objections, and next qualified action. Design a progression of
useful lessons, examples, proof, and offers with clear trigger and stop rules.
Return the sequence map and complete drafts. Measure downstream behavior, not
open rate alone.
