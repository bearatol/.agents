# Lead Magnet

Choose a narrow urgent problem for a qualified audience and promise a concrete
usable outcome. Select the lightest format that delivers value quickly. Map the
asset to the next product step without withholding essential instructions.
Return the concept, outline, full content plan, opt-in page copy, delivery email,
follow-up path, and measurement. Avoid generic checklists with no unique value.
