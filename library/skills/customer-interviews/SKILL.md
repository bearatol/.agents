# Customer Interviews

Define the learning goal and recruit people with relevant recent behavior.
Ask about specific past events, decisions, alternatives, constraints, and
language rather than hypothetical preferences. Avoid pitching or leading.
Capture exact phrases with consent, then code patterns across interviews.
Return the guide, recruitment criteria, note template, findings, counterexamples,
and confidence limits. Never fabricate quotes or participants.
