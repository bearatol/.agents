# Cold Email

Confirm lawful basis, target role, trigger, observable relevance, value,
credible proof, and a low-friction next step. Write concise messages with a
specific reason for contact and an easy opt-out. Create a small follow-up set
that adds new information instead of repeating the first email. Never invent
personalization, relationships, results, or urgency.
