# Messaging

Translate positioning into one primary promise, supporting benefits, proof,
mechanism, objections, and calls to action. Match vocabulary to verified
customer language and the audience's awareness level. Create a hierarchy that
can be reused across channels while adapting length and emphasis. Return a
message map with claim evidence and prohibited or unsupported claims.
