# Landing Page

Define the traffic source, audience, awareness, offer, primary action, proof,
and major objections. Build the page in decision order: relevance, value,
mechanism, outcomes, proof, fit, objections, risk reduction, and action. Specify
content and interface behavior for each section, including mobile constraints.
Return the outline, copy, proof requirements, analytics events, and review
checklist.
