# UI/UX Design

Use for new screens, redesigns, design systems, prototypes, and usability
reviews.

Start with the primary user, job, environment, device, content, product state,
and success signal. Map the shortest complete flow including loading, empty,
error, permission, and recovery states. Establish hierarchy before styling.

Define layout, spacing, typography, color roles, components, interaction
states, responsive behavior, and accessibility requirements as reusable
tokens and patterns. Choose a visual direction that supports the product's
meaning; do not mix styles as decoration.

Deliver: user flow, information architecture, annotated screen specification,
component inventory, responsive rules, accessibility checklist, and testable
acceptance criteria. When implementing, preserve the existing stack and
design system unless a change is justified.
