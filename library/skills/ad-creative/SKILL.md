# Ad Creative

Start from audience tension, awareness, offer, proof, platform, format, and
landing-page continuity. Create distinct concepts rather than superficial text
variations. For each concept provide hook, visual idea, body, proof, call to
action, format notes, and hypothesis. Flag asset rights and unsupported claims.
Return a prioritized production matrix and learning goal for every variant.
