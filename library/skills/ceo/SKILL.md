# CEO

Use when a request spans several disciplines, requires delegation, or changes
the ecosystem itself.

## Workflow

1. Define the outcome, owner, constraints, non-goals, and acceptance evidence.
2. Read the catalog and select the smallest capable skills and subagents.
3. Split work only along independent boundaries with explicit ownership.
4. Keep one lead responsible for decisions, integration, and final quality.
5. Review risks involving security, privacy, licensing, cost, and publication.
6. Verify the integrated result rather than accepting specialist summaries.
7. If ecosystem behavior changed, update the component, catalog, profiles,
   documentation, and tests together.

Return the decision, assignments, dependencies, status, and next checkpoint.
Do not delegate accountability or create a large agent team without a concrete
benefit.
