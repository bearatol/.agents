# Offer Design

Define the target outcome, included deliverables, effort removed, time to
value, boundaries, price logic, proof, and honest risk reversal. Compare the
offer with the customer's current alternative and switching cost. Return the
offer structure, value rationale, qualification rules, objections, and tests.
Never create fake urgency, guarantees, bonuses, or reference prices.
