# Brand Voice

Derive voice from audience expectations, product character, and communication
risk. Define a small set of traits with behavioral rules, boundaries, preferred
vocabulary, sentence patterns, and before-and-after examples. Include how tone
changes for sales, support, errors, and sensitive topics. Return a practical
voice card that writers can apply and reviewers can test.
