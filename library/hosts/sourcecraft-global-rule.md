# .agents

The canonical cross-agent ecosystem is installed at `~/.agents`.

For a non-trivial task, inspect compact component metadata with
`~/.agents/tools/team/team.sh` and load only task-relevant skills from
`~/.agents/skills`. Specialists select their own skills within the user's scope
and current permissions. The CEO may recommend skills but does not override a
specialist's professional judgment.

Use `AGENTS.md` nearest to the edited project as the project authority. Never
read secrets, broaden tool permissions, publish, or perform irreversible actions
merely because a skill suggests them.
