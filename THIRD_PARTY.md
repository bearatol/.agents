# Third-party Policy

The initial repository distribution contains original content only.

Catalog references to third-party projects are allowed when they contain the
official source URL, version or commit, license identifier, and installation
method. Referenced content is fetched only after an explicit user action.

Vendoring is allowed only after verifying redistribution rights. Required
copyright, license, attribution, and NOTICE files must remain intact. Content
with no license or a proprietary license is not copied into this repository.
